# Raw data

These files preserve the transliterated SMS text supplied by two residents, with subscriber numbers replaced by stable pseudonyms.

- `site_a_sms_redacted.txt` — longer series, currently extending back to November 2024.
- `site_b_sms_redacted.txt` — overlapping series used for corroboration and the 4 August 2026 event.

The raw files are evidentiary inputs. `../processed/events.csv` contains the conservative, manually reviewed event-level normalization.
